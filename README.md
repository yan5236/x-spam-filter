# X 垃圾机器人过滤器

## 📌 脚本简介

这是一个用于屏蔽 X（原 Twitter）平台上垃圾推广机器人评论和帖子的用户脚本。它会自动分析你时间线上出现的推文和评论，通过智能评分机制判断是否为垃圾账号，并将它们自动隐藏。

## 🎯 功能特点

### 智能评分机制

脚本会根据多个维度对每条推文进行打分，当总分达到阈值（≥5分）时，该推文会被自动隐藏：

- **高置信度垃圾话术匹配**：检测常见的机器人回复模板，如"应该没人比我...玩...开"、"我福不黑不信你看"等，每条命中直接加 5 分
- **用户名特征检测**：检测用户名中的特殊符号（如 🌸、♥、❤️），以及随机生成的字母数字组合用户名
- **内容关键词检测**：检测"同城"、"上门"、"喝茶"、"选妃"等推广类关键词
- **擦边词检测**：检测"涩"、"骚"等低俗擦边词汇
- **Emoji 密度检测**：当一条推文中 Emoji 数量超过 4 个时，会被加分

### 降低误伤的设计

- **不是简单关键词屏蔽**：采用加权打分机制，只有多项特征同时命中才会触发屏蔽
- **不是黑名单机制**：不会永久拉黑任何用户，只是隐藏当前推文，不会影响你查看该用户的其他正常内容

## 🚀 使用说明

1. **安装即用，零配置**：脚本安装后会自动运行，无需任何设置
2. **自动扫描**：页面加载时会自动扫描并隐藏垃圾内容，滚动加载新内容时也会自动处理
3. **查看日志**：如果你想了解脚本的工作情况，可以按 `F12` 打开浏览器的开发者工具，在 Console（控制台）中可以看到被屏蔽的推文日志，格式为：
   ```
   [屏蔽垃圾] 分数 被屏蔽的推文内容(前80字)
   ```

## ⚠️ 注意事项

- **工作原理**：脚本通过 CSS `display: none` 属性隐藏垃圾推文，推文实际上并没有被删除，只是在你这边看不到了
- **误伤处理**：如果发现正常推文被误屏蔽，可以尝试刷新页面，或者在本脚本的讨论区反馈，我会持续优化评分规则
- **适用范围**：目前仅支持 X 网页版（包括 x.com 和 twitter.com）
